# Табло ИИ-релизов

Анимация 16:9 о гонке ИИ-моделей — от запуска ChatGPT (30 ноября 2022) до сегодняшнего дня.
OpenAI (синий) и Anthropic (оранжевый) — главные герои. Google, xAI, Meta, DeepSeek, Alibaba (Qwen),
Moonshot (Kimi) и Mistral показаны такими же полноценными столбиками, но серыми с цветной верхушкой
(у Google — фиолетовой).

**Высота столбика — насколько модель «умная»** по индексу возможностей
[Epoch Capabilities Index (ECI)](https://epoch.ai/benchmarks/eci) от Epoch AI. ECI сводит десятки бенчмарков
в одну шкалу, где модели 2023 и 2026 годов можно сравнивать напрямую: Claude 3.5 Sonnet = 130, GPT-5 = 150.

## Как пользоваться

Откройте `index.html` в Chrome или Edge: прямо с диска или через GitHub Pages. На странице есть:

- **табло** — сама анимация 16:9;
- **транспорт** — пуск и пауза, переход к предыдущему/следующему релизу, скорость от 0,1× до 8×,
  масштаб времени и шкала перемотки с отметками всех релизов;
- **пульт справа**:
  - «Компании» — вкл/выкл каждую компанию или «Только OpenAI и Anthropic»;
  - «Релизы» — список всех моделей с поиском. Клик по модели — перемотка к её релизу и выделение;
  - «Вид» — стиль (сегменты, гладкий или пиксели), подписи, шкала, линия лидера, одинаковая высота вместо индекса,
    что листает мышь.

Мышью и колёсиком над табло листается время (или камера — переключается во «Виде»).
Клик по столбику выделяет модель крупной подписью.

| Клавиша | Действие |
|---|---|
| Пробел | пуск / пауза |
| ← → | предыдущий / следующий релиз |
| Shift + ← → | только релизы OpenAI и Anthropic |
| [ ] | месяц назад / вперёд |
| ↑ ↓ | быстрее / медленнее |
| + − 0 | приблизить / отдалить / весь период |
| O | только OpenAI и Anthropic ↔ все компании |
| L | подписи моделей |
| H | спрятать пульт: на экране остаётся только табло |
| Home / End | в начало / в конец |
| Esc | снять выделение |

Клавиши работают и в русской раскладке.

## Запись экрана

Нажмите H: пульт исчезнет, табло займёт всё окно, а курсор спрячется, если не двигать мышь.
Чтобы убрать и рамку браузера, включите его полноэкранный режим (F11, на Mac — ⌃⌘F).
Всеми клавишами из таблицы можно управлять и без пульта. Вернуть пульт — снова H или Esc.

**Автопрогон.** Нажмите «Пуск» — время идёт равномерно, 10 дней в секунду при скорости 1×: весь период
занимает около 2,5 минуты. В конце камера отъезжает и показывает весь график.

**Один анонс за раз.** Если компания в один день выпустила семейство моделей (GPT-5 с mini и Pro, Claude 4 с Opus
и Sonnet), на табло один столбик — фронтир-модель. Остальные модели семейства лежат в списке «Релизы», их можно
включить галочкой. Если в один момент выходят анонсы разных компаний, столбики появляются по очереди.

Автопрогон можно отрендерить и в файл, без записи экрана (Node 18+, `playwright`, `ffmpeg` с libx264):

```bash
node tools/render.mjs --out tablo-4k.mp4                 # 3840×2160, 25 к/с
node tools/render.mjs --out main-only.mp4 --only-main    # только OpenAI и Anthropic
```

## Данные

- `data/releases/*.json` — релизы с датами и ссылками на источники. Дата — первый день публичного доступа:
  чат, API или веса, включая публичные превью.
- `data/scores/eci_epoch_2026-09-23.json` — индекс ECI (Epoch AI, лицензия CC BY 4.0) на 23.09.2026.
- `tools/build_data.py` — сопоставляет релизы с индексом и собирает `js/data.js`.
  После правки данных запустите `python3 tools/build_data.py`.

Если у модели нет замера ECI, высота считается оценкой и в подписи стоит «≈». Источники оценок:

- для моделей 2025–2026 годов — пересчёт из Artificial Analysis Intelligence Index:
  ECI = 101,45 + 15,02 · ln(AA), r² = 0,94, ошибка около ±2 пунктов;
- для более старых моделей — оценки по LMArena или AA, ошибка около ±3 пунктов.

Модели совсем без данных, дубли и нишевые релизы по умолчанию скрыты. Их можно включить галочкой в списке «Релизы».
